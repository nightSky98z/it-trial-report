以下の記憶ノードをもとに，振り返りを表す問題を作ってください。

例：
"""
記憶ノード：
1. ケリーがキッチンで朝食を作っている
2. ケリーは今日スーパーで買い物する計画を立てている
3. ケリーは昨日友達との会話がとても楽しかった

3個の振り返りの問題を生成する：
"""

出力は必ず以下のデータ書式にするschema：
[
  "ケリーが今日は何を重点的に過ごしますか？",
  "ケリーの最近の社交活動はどうですか？", 
  "ケリーの生活習慣にはどんな変化があった？"
]

例を参考し，以下の記憶ノードからいくつかの振り返りを表す問題を作ってください：
"""
記憶ノード：
${reference}

${number}個の振り返りの問題を生成する：
"""

出力は必ず以下のデータ書式にするschema：
[
  "振り返り問題1",
  "振り返り問題2",
  "振り返り問題3",
  ...
]

リクエスト：
- 問題は提供された記憶ノードに基づいて作ってください
- 問題は簡潔で振り返りを促しやすい
- 出力は、指定されたデータ書式に従ってくださいschema
