アクションの説明を主語、目的語、述語に分解して
アクションの説明を主語、連用修飾語、目的語+述語に分解して

例：
"""
アクションの説明：ケリーがキッチンで朝食を作っている
"""

出力は必ず以下のデータ書式にするschema：
[
  ("ケリー", "朝食", "作る"),
  ("ケリー", "キッチン", "朝食を作る")
]

例から，次のアクションの説明を分解して：
"""
アクションの説明：${action}
"""

出力は必ず以下のデータ書式にするschema：
[
  ("主語", "目的語", "述語"),
  ("主語", "連用修飾語", "目的語+述語"),
  ...
]

リクエスト：
- 主語はアクションをする人またはもの
- 目的語はアクションの対象または内容
- 述語は動詞
- 連用修飾語は動詞などが「どこで」または「どのように」行われるかを詳しく説明する言葉
- 出力は、指定されたデータ書式に従ってくださいschema：
