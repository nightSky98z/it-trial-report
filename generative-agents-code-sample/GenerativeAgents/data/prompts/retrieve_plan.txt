以下の記憶ノードをもとに，エージェントのスケジュールを説明してください。

例：
"""
記憶ノード：
2023-12-15 08:00: ケリーがキッチンで朝食を作っている
2023-12-15 09:00: ケリーは今日スーパーで買い物する計画を立てている
2023-12-15 14:00: ケリーは昨日友達との会話がとても楽しかった

5個のスケジュール説明文を生成してください：

[
  "ケリーは今朝、栄養のある朝食を準備した",
  "ケリーは生活用品を買いにスーパーへ行く予定だ",
  "ケリーは友人との人間関係を大切にしている",
  "ケリーは規則正しい生活を送っている",
  "ケリーは健康的な食生活を重視している"
]

例を参考し，以下の記憶ノードをもとにスケジュール説明文を生成してください：
"""
記憶ノード：
${description}

エージェント：${agent}
現在の日時：${date}
"""

出力は必ず以下のデータ書式にするschema：
[
  "スケジュール説明文1",
  "スケジュール説明文2",
  "スケジュール説明文3",
  ...
]

リクエスト：
- スケジュール説明文は必ず記憶ノードをもとに作ること
- 説明文は簡潔で分かりやすく、エージェントの生活習慣に即したものとしてください
- 出力は、指定されたデータ書式に従ってくださいschema
